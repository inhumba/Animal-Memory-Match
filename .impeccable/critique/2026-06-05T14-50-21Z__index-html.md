## Overall Impression

This crossed from "good foundation" to "confident kids product." Onboarding hints, contrast fixes, victory SR hardening, and canvas loop lifecycle closed the gaps from the prior 36/40 run. The remaining work is polish: sync docs, trim setup eyebrows, and optionally harden live reduced-motion.

## What's Working

1. **Quieter HUD with preserved semantics.** Unified neutral pill surfaces with muted pink/teal/amber ink — Flips and Pairs Left read instantly; Best hides during play so the header stays focused.
2. **Setup teaches before play.** Theme hero, pair counts under each difficulty chip, live diff-summary, and "Let's match N pairs!" CTA answer Jordan's "how hard is this?" before the first flip.
3. **Accessible victory + controls loop.** Focus trap, Escape → menu, `inert` when closed, plain-text star summary announced on dialog open, dynamic keyboard hints, and `aria-describedby` on canvas make the game workable for keyboard and SR users.

## Priority Issues

### [P2] `prefers-reduced-motion` captured once at load
- **Why it matters:** OS setting changes mid-session won't disable shake, particles, or confetti. Sam enabling reduced motion after a flashy round still gets motion.
- **Fix:** Read `matchMedia(...).matches` at decision time or add a `change` listener that updates a shared flag.
- **Suggested command:** `/impeccable harden index.html`

### [P3] DESIGN.md drift from shipped UI
- **Why it matters:** Docs still describe glass header, rainbow play gradient, saturated stat pills, and old CTA copy. Future `/impeccable` commands will target patterns you've already replaced.
- **Fix:** Regenerate tokens/components for quieter HUD, `.ink-secondary`, OKLCH amber CTA, setup hero, victory SR patterns, and game-loop lifecycle.
- **Suggested command:** `/impeccable document index.html`

### [P3] Setup section eyebrows add reflex noise
- **Why it matters:** Tiny uppercase tracked labels on every setup section ("Pick a theme", "How many pairs?") are the AI eyebrow scaffold. Hero subtitle already states the task; eyebrows duplicate it.
- **Fix:** Drop eyebrows and let the hero subtitle + chip labels carry section identity, or merge into one combined prompt above both grids.
- **Suggested command:** `/impeccable distill setup-screen`

## Persona Red Flags

**Jordan (First-Timer, age 6–8):** Can identify Safari hero and Medium default within seconds. Mute icon is still icon-only for sighted kids (aria-label helps SR only). No preview that cards will speak aloud until first flip.

**Casey (Distracted Mobile User):** Play CTA sits in thumb zone on phone. "More themes" expansion can push content tall on small screens (mobile scroll is acceptable). No state persistence if interrupted mid-game before victory.

**Sam (Accessibility-Dependent):** Full keyboard path through setup chips, canvas grid, and victory dialog with focus trap. Keyboard hints now visible on desktop during play. Gap: reduced-motion not reactive mid-session.

**Maya (6-year-old independent player):** Loves the lion hero and rocket CTA. "Expert, 12 pairs" is visible now, but 12 pairs may still feel scary without a visual board-size cue on mobile.

## Minor Observations

- Browser flagged **nested cards** on the setup panel wrapper — the warm gradient panel inside the main workspace reads as card-in-card; consider flattening to a single surface.
- Theme hero card shadow (`0 14px 36px`) is the loudest element left in setup; intentional delight, but competes slightly with quieter header.
- RAF continues through victory celebration (confetti needs frames); optional optimization once particles drain.
- Tailwind CDN still compiles on first load; preconnect helps fonts but not JIT cost.

## Questions to Consider

- Does Expert difficulty need a one-line size cue ("big board!") for kids who can't preview the canvas on mobile?
- What would removing both eyebrows do to scan time for caregivers setting up a round?
